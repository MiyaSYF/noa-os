005_Style Crushed Capability

v5 training finished in about twelve minutes, then failed broadly in evaluation. This entry records the U+DCE3 input bug and the model failures that remained after it was removed.

Closed: Ghost Character U+DCE3

Pasting Japanese worked, but deleting one character and typing it again caused the tokenizer to crash. An invalid surrogate character had entered the user message after terminal editing damaged a multibyte UTF-8 sequence. The fix is to validate Unicode strictly before input reaches history or the prompt template, and to reject invalid input instead of silently changing it.

Before blaming the model, verify that the bytes contain the sentence you thought you sent.

Open: Evaluation Still Fails

  • The model is inconsistent about its name.
  • It invents titles for real-world works.
  • It loses track of a game-selection task.
  • It handles ordinary, unseen topics such as laundry awkwardly.

Style and capability may be trading off, but that is still a hypothesis. Checkpoint 70 is only a provisional baseline. The next evaluation must include questions unfamiliar to both the model and the person writing them.

The model answers the sentence in the bytes, not the sentence on the screen.
